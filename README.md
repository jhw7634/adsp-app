# ADsP 오답킬러

ADsP(데이터분석 준전문가) 자격증 대비 퀴즈 웹앱 (홈 화면에 설치 가능, 오프라인 지원).

- `index.html` 앱, `questions.js` 문제은행과 공부 탭 설명, `manifest.webmanifest`·`sw.js`·`icon-*.png` 설치용
- `python3 check.py`: 문제 형식을 검사하고, R 코드가 달린 문제·예시는 R로 실제 실행해서 정답을 확인 (`Rscript` 필요)
- 모든 문제·보기·해설·아이콘은 새로 작성했습니다. 기출·교재 문장을 옮겨 오지 않습니다.
- 본 앱은 시험 주관 기관과 관련 없는 개인 학습용 앱입니다.
